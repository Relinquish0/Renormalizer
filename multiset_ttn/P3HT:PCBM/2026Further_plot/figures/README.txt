Data File Description:
- extrpolated_alldof2.npy: Extrapolated dynamics
- mps_M256_dt1_nb18_run2.npz: MPS simulation trying to reproduce the literature.
- MPS.npz: Chain simulation reported in the main text of the manuscript. (all bond dimension)
- mps4.npz: ChainX simulation reported in the main text of the manuscript. (all bond dimension)
- ref.npy: Reference dynamics from the literature, extracted from the figures.
- Tree5.npz: Tree simulation with exactly the same configuration in the literature (all bond dimension and to reproduce)
- Tree4.npz: TreeX simulation reported in the main text of the manuscript. (all bond dimension)
- dt.npz: Convergence benchmark for time evolution step for TDVP-PS
